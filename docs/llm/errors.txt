# rill error handling

Atoms, status sidecars, `guard`, `retry`, vacancy, and recovery patterns.

## Two failure modes

| Failure | Caused by | Caught by |
|---|---|---|
| Runtime error (uncatchable) | `error`, `assert`, parameter type mismatch | nothing — propagates |
| Access halt (catchable) | Accessing an **invalid value** (status sidecar populated, e.g. failed `:type` assertion, extension `ctx.invalidate`, divide-by-zero (`RILL-R002`), OOB index (`RILL-R009`), missing field (`RILL-R007`), or failed conversion (`RILL-R038`)) | `guard { }`, `retry<limit: N> { }` |

## Assert and error

    5 -> assert ($ > 0)                    # returns 5
    -1 -> assert ($ > 0)                   # halts: Assertion failed
    "" -> assert !.empty "Input required"  # halts with custom message
    $val -> assert $:?list "Expected list"

    error "Something went wrong"           # halt with message
    "Operation failed" -> error            # piped form (must be string)
    error "Status: {$code}"                # interpolation works

## Status sidecar

Every value carries a status sidecar. Read with `.!`:

| Probe | Returns |
|---|---|
| `$v.!` | bool: is this an invalid value? |
| `$v.!code` | atom: error code (`#ok` on valid values) |
| `$v.!message` | string: human-readable description |
| `$v.!provider` | string: component that produced the error |
| `$v.!trace` | list: trace frames |

`.!` NEVER halts, even on invalid values. Safe to inspect.

## Atoms

Named symbols, compared by name. Names are case-sensitive; error codes are uppercase by convention. Type name is `atom`.

    #TIMEOUT                       # atom literal
    #TIMEOUT == #TIMEOUT           # true (same name)
    #TIMEOUT -> string             # "TIMEOUT" (no # sigil)
    "TIMEOUT" -> atom              # #TIMEOUT
    "BOGUS" -> atom                # #BOGUS (any well-formed name)
    "ok" -> atom                   # #ok
    "1x" -> atom                   # halts #INVALID_INPUT (malformed name)
    #wired                         # atom (lowercase names are valid)
    #timeout == #TIMEOUT           # false (case-sensitive)
    #TIMEOUT:?atom                 # true

Built-in atom literals. The core error set is every built-in atom except #ok and #IGNORE:

    #RILL_R###                     # 36 atoms, one per halting registry error (e.g. #RILL_R002); see BUILTIN_ATOMS
    #R001                          # parse-recovery node, host-built retry node
    #R999                          # unhandled extension throw
    #TIMEOUT  #AUTH  #FORBIDDEN  #RATE_LIMIT  #QUOTA_EXCEEDED
    #UNAVAILABLE  #NOT_FOUND  #CONFLICT
    #INVALID_INPUT                 # also: `sort` key extractor returned vacant;
                                   #       negative n for take/skip;
                                   #       n <= 0 for batch/window;
                                   #       step <= 0 for window;
                                   #       negative/non-integer count for repeat(), .repeat, .pad_start, .pad_end;
                                   #       non-positive or non-integer concurrency for fan/filter;
                                   #       unknown option key for fan/filter;
                                   #       zero step for range;
                                   #       non-integer index for [], .(n), .at, list dispatch;
                                   #       zero step for slice<>;
                                   #       negative duration .subtract result, negative .multiply factor,
                                   #       non-finite or fractional-month .multiply result, .total_ms on calendar duration;
                                   #       vector dimension mismatch for .similarity/.dot/.distance
    #PROTOCOL  #DISPOSED
    #TYPE_MISMATCH                 # failed `:type` assertion;
                                   # also: `sort` key extractor mixed types,
                                   #       `sort` `key_fn` not callable,
                                   #       tuple comparison length/type mismatch,
                                   #       start_when/stop_when predicate non-bool,
                                   #       wrong-typed argument to duration()/datetime() or datetime/duration methods,
                                   #       non-vector argument to .similarity/.dot/.distance,
                                   #       non-dict options for fan/filter,
                                   #       non-number concurrency for fan/filter,
                                   #       filter predicate returns non-bool
    #IGNORE                        # sentinel for `pass<on_error: #IGNORE> { body }`

`.!code` reports `#ok` on valid values. `#ok` is a sentinel, not an error code, but it is writable as a literal. `$v.!code == #ok` tests for a valid value; `.!` is shorter.

The core error set is closed: every built-in atom except `#ok` and `#IGNORE`. Hosts cannot add codes; they report a domain failure with the nearest core code and put the detail in `raw`.

## Guard

Runs the body once. If body halts with a catchable signal, returns the invalid value instead.

    "ok" => $v
    guard { $v.upper }              # "OK"

    guard { "x":number } => $out    # catches access halt
    $out.!                          # true
    $out.!code -> string            # "TYPE_MISMATCH"
    $out.!message                   # "Type assertion failed: expected number, got string"

Filtered form (catches only matching codes):

    guard<on: #TIMEOUT> {
      $app.fetch($url)
    }

    guard<on: list[#TIMEOUT, #UNAVAILABLE]> {
      $app.fetch($url)
    }

Every `on:` name must be in the core error set. A name outside it, and `on: list[]`, are parse errors (`RILL-P004`). A bare `guard { ... }` catches every catchable halt.

`guard` does NOT catch halts from `error`, `assert`, or a parameter type mismatch. Those propagate. `guard` DOES catch divide-by-zero (`RILL-R002`), out-of-bounds index (`RILL-R009`), missing field access (`RILL-R007`), failed conversion (`RILL-R038`), and a `filter` predicate that returns an invalid value (`RILL-R001`) — these behave like any other access halt.

## Retry

Re-enters body up to N times. `limit:` is required and must be a positive integer.

    retry<limit: 3> {
      $app.fetch($url)
    } => $result

    retry<limit: 3, on: #UNAVAILABLE> {
      $app.fetch($url)
    }

    retry<limit: 3, on: list[#UNAVAILABLE, #TIMEOUT]> {
      $app.fetch($url)
    }

Each failed attempt appends a `guard-caught` trace frame. Bare `retry<3>` is a parse error.

## Vacancy and `??`

A value is **vacant** when empty (`""`, `0`, `false`, `list[]`, `dict[]`) or invalid. `??` returns the fallback when the left side is vacant:

    dict[a: 1] => $d
    $d.missing ?? "default"         # "default"
    $d.a ?? "default"               # 1

    guard { "x":number } => $out
    $out ?? "fallback"              # "fallback" (invalid is vacant)

## Existence check without halting

`.?field` returns a boolean; never halts. See `types` for type-combined checks like `.?field&string`.

## Timeout error atoms

| Atom | Cause | Recovery |
|---|---|---|
| `#RILL_R082` | `timeout<total:>` wall-time expired | `guard { timeout<total:...> { ... } } ?? fallback` |
| `#RILL_R083` | `timeout<idle:>` inactivity window expired | `guard { timeout<idle:...> { ... } } ?? fallback` |

Expiry produces a catchable halt. Wrap `timeout<>` in `guard` to catch it as an invalid value; use `??` for a one-liner fallback. Direct `??` on a bare `timeout<>` expression does NOT intercept expiry halts.

    guard { timeout<total: duration(0,0,0,0,0,0,500)> { $app.fetch($url) } } => $r
    $r ?? "cached"

    ($r.!code == #RILL_R082) ? "timed out" ! $r

## Recovery patterns

Check before access:

    $v.! ? "invalid" ! $v.upper

Guard then inspect:

    guard { $v.upper } => $out
    $out.! ? "failed: {$out.!message}" ! $out

Retry with fallback:

    retry<limit: 3> { $app.fetch($url) } => $result
    $result ?? "fallback"

Branch on error atom (flat chain, each comparison parenthesized):

    guard { $app.fetch($url) } => $result
    ($result.!code == #TIMEOUT) ? "timed out"
      ! ($result.!code == #AUTH) ? "auth failed"
      ! ($result.!code == #RILL_R082) ? "total timeout"
      ! ($result.!code == #RILL_R083) ? "idle timeout"
      ! $result.! ? "error: {$result.!message}"
      ! $result
